# Music Bot - Бот для отслеживания музыки

Бот для автоматического отслеживания и отправки информации о прослушиваемой музыке в Telegram группу на основе данных Last.fm API.

Работу бота можно оценить тут - https://t.me/me0ws_s

## Описание

Этот бот отслеживает вашу активность в Last.fm и автоматически отправляет информацию о текущем треке или последнем прослушанном треке в указанную Telegram группу. Бот обновляет сообщения каждые 10 минут и показывает:

- Название трека и исполнителя
- Статус воспроизведения (сейчас слушает / прослушан ранее)
- Время прослушивания
- Обложку трека
- Ссылку на трек в Last.fm

## Возможности

- ✅ Отслеживание текущего трека в реальном времени
- ✅ Отображение последнего прослушанного трека
- ✅ Автоматическое обновление сообщений каждые 10 минут
- ✅ Красивое форматирование с Markdown
- ✅ Отображение обложек треков
- ✅ Ссылки на треки в Last.fm
- ✅ Удаление старых сообщений при обновлении

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd music-bot
```


### 2. Настройка переменных окружения

Создайте файл `.env` в корневой папке проекта:

```env
LASTFM_API_KEY=ваш_ключ_lastfm_api
LASTFM_USERNAME=ваш_username_lastfm
TELEGRAM_TOKEN=токен_вашего_бота
CHAT_ID=id_группы_или_канала
```

### 3. Получение необходимых ключей

#### Last.fm API Key

1. Зарегистрируйтесь на [Last.fm](https://www.last.fm/)
2. Перейдите в [API settings](https://www.last.fm/api/account/create)
3. Привяжите Spotify к профилю LastFM
4. Создайте новое приложение и получите API Key

#### Telegram Bot Token

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота

#### Chat ID

1. Добавьте бота в нужную группу/канал
2. Отправьте сообщение в группу
3. Получите Chat ID через [@userinfobot](https://t.me/userinfobot) или другие способы

### 5. Запуск бота

```bash
python main.py
```

## Функции

### Отслеживание треков

- Бот проверяет текущий трек через Last.fm API
- Если нет активного трека, показывает последний прослушанный
- Обновляет информацию каждые 10 минут

### Форматирование сообщений

- Использует MarkdownV2 для красивого отображения
- Показывает статус воспроизведения (🟢 сейчас слушает / ⏸️ прослушан ранее)
- Отображает время прослушивания
- Включает ссылку на трек в Last.fm

### Управление сообщениями

- Автоматически удаляет старые сообщения при обновлении
- Сохраняет ID сообщений в файл для восстановления после перезапуска
- Отправляет сообщения без уведомлений

## Технические детали

- **Язык**: Python 3.7+
- **Библиотеки**: aiogram, pylast, python-dotenv
- **API**: Last.fm API, Telegram Bot API
- **Интервал обновления**: 10 минут
- **Формат сообщений**: MarkdownV2 с fallback на обычный текст

## Логирование

Бот ведет логи с уровнем WARNING и выше. Логи включают:

- Информацию об отправке сообщений
- Ошибки при работе с API
- Предупреждения о проблемах с удалением сообщений

## Возможные проблемы

1. **Ошибки API Last.fm**: Проверьте правильность API ключа и username
2. **Ошибки Telegram**: Убедитесь, что бот добавлен в группу и имеет права на отправку сообщений
3. **Проблемы с обложками**: Бот использует fallback обложку при ошибках загрузки
