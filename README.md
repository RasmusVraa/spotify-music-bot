# Music Bot - Бот для отслеживания музыки

Бот для автоматического отслеживания и отправки информации о прослушиваемой музыке в Telegram группу на основе Spotify Web API.

Работу бота можно оценить тут - https://t.me/swagah0llic

## Описание

Этот бот отслеживает вашу активность в Spotify и автоматически обновляет сообщение о текущем треке или последнем прослушанном треке в указанной Telegram группе. Бот показывает:

- Название трека и исполнителя
- Статус воспроизведения (сейчас слушает / прослушан ранее)
- Время прослушивания
- Обложку трека
- Ссылку на трек в Spotify

## Возможности

- ✅ Отслеживание текущего трека в реальном времени
- ✅ Отображение последнего прослушанного трека
- ✅ Автоматическое обновление сообщений каждые 10 минут
- ✅ Красивое форматирование с Markdown
- ✅ Отображение обложек треков
- ✅ Ссылки на треки в Spotify
- ✅ Редактирование одного сообщения при обновлении

## Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <repository-url>
cd music-bot
```


### 2. Настройка переменных окружения

Создайте файл `.env` в корневой папке проекта:

```env
SPOTIFY_CLIENT_ID=ваш_spotify_client_id
SPOTIFY_CLIENT_SECRET=ваш_spotify_client_secret
SPOTIFY_REDIRECT_URI=http://127.0.0.1:8888/callback
TELEGRAM_TOKEN=токен_вашего_бота
CHAT_ID=id_группы_или_канала
```

### 3. Получение необходимых ключей

#### Spotify API (бот живёт на сервере)

Spotify один раз требует вход через браузер. Бот при этом остаётся на сервере, ПК не нужен — ссылку можно открыть с телефона.

1. Создайте приложение на [Spotify Developer Dashboard](https://developer.spotify.com/dashboard)
2. Скопируйте Client ID и Client Secret в `.env` на сервере
3. В Redirect URIs добавьте: `http://127.0.0.1:8888/callback`
4. По SSH: `pip install -r requirements.txt`
5. По SSH: `python main.py --auth`
6. Откройте выданную ссылку **на телефоне**, нажмите Agree
7. Телефон откроет `http://127.0.0.1:8888/callback?code=...` (страница не загрузится — так и должно быть)
8. Скопируйте адрес из строки браузера и вставьте в SSH **или** выполните:

```bash
python main.py --auth --code 'вставьте_сюда_весь_адрес'
```

9. На сервере появится `spotify_tokens.json`. После этого: `python main.py`

#### Telegram Bot Token

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Получите токен бота

#### Chat ID

1. Добавьте бота в нужную группу/канал
2. Отправьте сообщение в группу
3. Получите Chat ID через [@userinfobot](https://t.me/userinfobot) или другие способы

### 5. Запуск бота

```bash
python main.py
```

## Функции

### Отслеживание треков

- Бот проверяет текущий трек через Spotify Web API
- Если ничего не играет, показывает последний прослушанный трек
- Обновляет одно и то же Telegram-сообщение

### Форматирование сообщений

- Использует MarkdownV2 для красивого отображения
- Показывает статус воспроизведения (🟢 сейчас слушает / ⏸️ прослушан ранее)
- Отображает время прослушивания
- Включает ссылку на трек в Spotify

### Управление сообщениями

- Редактирует существующее сообщение при смене трека
- Сохраняет ID сообщения в файл для восстановления после перезапуска
- Отправляет сообщения без уведомлений

## Технические детали

- **Язык**: Python 3.7+
- **Библиотеки**: aiogram, aiohttp, python-dotenv
- **API**: Spotify Web API, Telegram Bot API
- **Интервал обновления**: 10 минут
- **Формат сообщений**: MarkdownV2 с fallback на обычный текст

## Логирование

Бот ведет логи с уровнем WARNING и выше. Логи включают:

- Информацию об отправке сообщений
- Ошибки при работе с API
- Предупреждения о проблемах с удалением сообщений

## Возможные проблемы

1. **Ошибки Spotify**: Проверьте Client ID/Secret, Redirect URI и запустите `python main.py --auth`
2. **Ошибки Telegram**: Убедитесь, что бот добавлен в группу и имеет права на отправку сообщений
3. **Проблемы с обложками**: Бот использует fallback обложку при ошибках загрузки
